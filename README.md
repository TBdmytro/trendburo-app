# Trend Büro — приложение, админка и импорт товаров

Витрина (`index.html`) плюс админка (`admin.html`), которая сама загружает ассортимент из источников (LV, Dior, Gucci, поставщики очков, CSV/JSON), считает цены по правилам и публикует товары после проверки.

## Состав

| Путь | Что это |
|---|---|
| `index.html` | Витрина (Telegram Mini App / веб). Берёт опубликованные товары из `/api/catalog`. Демо-данные открываются только по `?demo=1` и помечены плашкой «ДЕМО-ДАННЫЕ». |
| `admin.html` | Админка: источники, импорт, задачи, предпросмотр, товары, цены. |
| `api/admin.js` | API админки (вход по паролю, подписанная cookie, защита от CSRF). |
| `api/catalog.js` | Публичный каталог: только опубликованные товары, без закупочных цен и наценки. |
| `api/cron.js` | Плановое обновление цен и наличия, фоновая обработка задач. |
| `lib/` | Логика: безопасная загрузка, разбор страниц, нормализация, дубли, цены, очередь задач, публикация. |
| `test/` | 41 автотест. Фикстуры в `test/fixtures` используются только тестами (тестовый режим). |

## Развёртывание

1. **GitHub**: создайте пустой репозиторий и загрузите в него этот код.
2. **Sanity**: создайте новый проект на sanity.io/manage, dataset `production`. В разделе API → Tokens создайте токен с правами **Editor**.
3. **Vercel**: импортируйте репозиторий (Framework: Other). В Settings → Environment Variables добавьте:

| Переменная | Значение |
|---|---|
| `SANITY_PROJECT_ID` | ID проекта Sanity |
| `SANITY_DATASET` | `production` |
| `SANITY_TOKEN` | токен Editor (только здесь, никуда больше) |
| `ADMIN_PASSWORD` | пароль входа в админку |
| `ADMIN_SECRET` | необязательно: случайная строка 32+ символов для подписи сессии |
| `CRON_SECRET` | случайная строка, её же Vercel передаёт в cron |

4. **Фоновая обработка**: Vercel Cron (Hobby) запускается раз в сутки (`vercel.json`). Чтобы большие импорты шли без открытой админки, в GitHub → Settings → Secrets добавьте `APP_URL` (адрес сайта) и `CRON_SECRET`. Тогда `.github/workflows/import-tick.yml` будет продвигать очередь каждые 10 минут. Пока админка открыта на вкладке «Задачи», очередь продвигается и оттуда.

## Как запустить полный импорт бренда

1. Откройте админку, вкладку «Источники», и проверьте бренд: регион, частоту обновления, авто-обновление. Если бренд разрешил использовать фото, включите «Копировать фото» и заполните поле «Основание» (кто и когда разрешил). Без основания фото остаются ссылками на сайт бренда и в хранилище не копируются.
2. На вкладке «Импорт» выберите источник и режим:
   - «Ссылка на товар»;
   - «Несколько ссылок»;
   - «Категория» (ссылка на раздел);
   - «Весь ассортимент» (по sitemap).
3. На вкладке «Задачи» видно ход работы: найдено, обработано, ошибки, повторы.
4. На вкладке «Предпросмотр» проверьте разделы «Новые», «Обновления», «Возможные дубли», «Неполные», «Ошибки», «Изменения цен» и «Отчёт покрытия». Затем «В черновики» или «Опубликовать выбранные».

Если сайт отвечает защитой от ботов (CAPTCHA, вход, блокировка), задача останавливается со статусом «Заблокировано». Обход не выполняется: источник нужно подключить через файл или фид.

## Цены

- Официальный сайт бренда:
  - Украина: цена бутика × 1,10, доставка включена;
  - Европа и Дубай: цена бутика × 1,08 плюс доставка.
- Очки от поставщиков: правила А/Б/В из ТЗ (порог скидки 20%, граница 400 €).
- **Округление**: до 5 € по обычным правилам (277,5 → 280; 1023 → 1025). Шаг и направление настраиваются во вкладке «Цены».
- Новые правила сохраняются только после просмотра предпросмотра расчётов. Затем цены опубликованных товаров пересчитываются.
- Закреплённая вручную цена задаётся для Украины. Европа и Дубай считаются от неё своими коэффициентами.
- Товар не публикуется, если итог ниже закупки плюс расходы или если цена бутика неизвестна.

## Наличие и обновление

- Статусы: «Можно заказать онлайн», «В бутике», «Нет в наличии», «Предзаказ», «Уточнить».
- Данные старше 48 часов показываются как «Уточнить».
- Плановое обновление (ежедневно или еженедельно, для каждого источника отдельно) меняет цену и наличие у существующих товаров. Ручные правки при этом сохраняются.
- Если источник временно недоступен, прежняя цена остаётся, а ошибка записывается в предложение.

## Ограничения

- С серверов Vercel сайты брендов могут отвечать защитой от ботов. Это видно только после первого реального запуска. В таком случае нужен фид (например, партнёрский фид Gucci после одобрения) или CSV.
- Адреса sitemap для LV и Gucci не проверены вживую: без sitemap работают режимы «ссылка» и «категория».
- У OpticalH нет открытого каталога, нужна ссылка или файл от поставщика.
- Покупки не выполняются, сообщения клиентам не отправляются.
